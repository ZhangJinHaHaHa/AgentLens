# AgentLens Bug Audit - 2026-06-10

## Scope

- GitHub open issues #1, #2, #4, #5, #9, #10 in `ZhangJinHaHaHa/AgentLens`.
- High-risk local paths for the current MVP:
  - contracts funds flow
  - ZK proof verification
  - JSON-RPC writeback
  - frontend chain ABI clients
  - current deployed frontend bundle check

## Fixed in this pass

| Area | Fix |
| --- | --- |
| Marketplace overpayment | `AgentMarketplace.rentAgent` and `buyAgent` now require exact payment and record the exact expected amount. |
| Marketplace trapped payments | Added owner-only `withdrawPayments(to, amount)`. |
| Registry trapped service fees | Added owner-only `withdrawServiceFees(to, amount)` to V1/V2/V3 registries. |
| Registry trapped developer bond | Added operator/owner `releaseBond(tokenId, amount)` to V1/V2/V3 registries. |
| Receipt polling | Added `receiptTimeoutMs` to JSON-RPC write client; missing receipts now time out instead of hanging forever. |
| V2/V3 ABI mixup | `createAgentAuditRegistryV2Client` uses the V2 ABI; V3 reads use a separate `createAgentAuditRegistryV3Client`. |
| ZK proof replay | `ZkAuditVerifier` now rejects reused proof hashes with `PROOF_REPLAYED`. |
| ZK compile coverage | `ZkAuditVerifier` is now included in `contracts/scripts/compileV2.js`. |
| Regression tests | Added tests for exact marketplace payment, marketplace withdrawal, service fee withdrawal, bond release, and receipt timeout. |

## Not a current bug

| Issue | Result |
| --- | --- |

| Sandbox dependency injection issue | The GitHub issue is positive feedback, not a bug. |

## Remaining risks to track

| Risk | Severity | Notes |
| --- | --- | --- |
| Sandbox production dependency audit | High/Critical | `npm audit --omit=dev` reports critical issues through `cos-nodejs-sdk-v5` transitive dependencies (`request`, `fast-xml-parser`, `form-data`). Fixing safely likely needs dependency upgrade/testing, not a small bug patch. |
| Frontend production dependency audit | Moderate | `ethers`, `react-router-dom`, and `postcss` report moderate advisories. Most are patch/minor upgrades, but should be handled as a separate dependency PR. |
| Marketplace payout semantics | Product/design | `withdrawPayments` lets owner withdraw market payments, but there is still no seller split/settlement accounting in the contract. This matches current MVP but is not enough for production marketplace settlement. |
| Slashed bond final destination | Product/design | Slashed funds remain in the contract unless later compensated/released through business process. A production design should define whether slashed funds go to users, platform reserve, or insurance pool. |
| Deployed frontend freshness | Operational | `http://[redacted-server]:5173/zh/agents` serves `index-Cxiu_5g9.js`; local build after fixes is `index-DES8YSSs.js`, so the server is not on this latest local code. |
